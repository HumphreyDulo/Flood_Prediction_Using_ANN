# Flood Prediction App

This project predicts flood risks and identifies safe zones based on geographic, climatic and human data. It uses Flask for the backend and Leaflet.js for interactive maps.

The application is fully automated in its data entry through use of APIs.

In addition, It can provide safezones from flood-prone areas within a 5KM radius.

## Features
- Flood risk prediction based on user location.
- Interactive map with safe zones within a 5km radius.
- Integration with human, climatic and geographic data APIs.
